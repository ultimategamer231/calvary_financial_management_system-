# Staff workflows
- Choose member, guest or anonymous → enter currency and split → review → transactional post → receipt lookup and print/PDF.
- Find erroneous collection → review original → enter reason → void or atomically replace → inspect original and replacement receipts.
- Assign named member or explicit group snapshot → review amount per member and due date → select obligation during collection → reconcile remaining, including after void.
- Enter payee, category, date and amount → attach private evidence → post expense → reconcile in period report. Clean up abandoned uploads safely.
- Filter report → inspect underlying entries → export same selection → compare independent totals.
- Operator verifies replacement identity, provisions invited account, atomically rebinds slot and audits replacement. Verify both revoked-session denial and new access. Password recovery uses an allowlisted redirect.
